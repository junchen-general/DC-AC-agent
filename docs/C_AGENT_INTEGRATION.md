# C 磁热力自动接入与验收

## 调用流程

`run_multiphysics(run_id?, options?)` → 查找当前修订的成功电气运行（缺失时先执行电气仿真）→ 校验会话、修订、参数及真实来源 → 读取 `electrical_raw_v1.mat` → MATLAB PDE 求解 → 校验结果格式和源文件哈希 → 发布 `multiphysics_result.json` → 网页展示指标与四张云图。

按钮针对所选电气运行；旧修订拒绝求解。Agent只能传运行编号和四个边界参数，不接受路径或任意MATLAB代码。工具、规则模式及按钮共用串行队列和MATLAB进程锁。取消/超时终止本次进程；每次尝试独立存于父运行的 `fields/<attempt>/`，保留日志和历史工件。最新失败/取消状态不会继续显示前次成功结果为本次成功。

## 参数与物理范围

固定候选：E70 N87、68匝、2.5 mm气隙、64股×0.15 mm铜线截面积假设。材料与几何沿用C研究文件，每次复制到运行目录。磁场用父运行末尾四个周期最大绝对电感电流，热场用同窗RMS电流与候选R20计算直流铜热，并以峰值温度反馈电阻。不是将电气模型0.25 Ω直接当成候选绕组电阻。

可选边界：ambient_c（−20至100°C）、convection_w_m2k（5至50）、extra_winding_heat_w和core_heat_w（各0至20 W）；默认40、10、0.5、0.5。后两项是指定热源，不是交流铜损或磁芯损耗预测。前后端面绝热、外周对流、理想粘结，二维线性磁场与平面应力，最小约束支撑。

输入和输出L/R差异在网页及回复中列明。未自动回填电气模型，未完成参数闭环优化。没有非线性饱和、磁滞、接触/预紧、磁致伸缩、电磁力及整机效率结论。应力采用磁芯探针值；角点云图峰值受网格影响，不能直接用于强度判定。
