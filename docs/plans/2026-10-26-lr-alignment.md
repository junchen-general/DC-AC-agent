# L/R 回填与复验计划

目标：保留 2 mH、0.25 Ω 基准，从成功的 C 数值结果读取候选 L 和 R20，以新设计修订回填电气模型。电路电阻参考温度为 20°C；热场内部的温度反馈保持原有定义，不宣称电热双向迭代。

实施顺序：

1. 验证本机 R2023b 的 SPS/PDE 能力；保留不兼容或失败日志。
2. 为候选回填编写测试：拒绝旧修订、错误归属、非数值结果、源文件变化及无效 L/R；成功时保存参数、父运行和源文件哈希，旧运行不变。
3. 实现独立回填模块及 Agent 入口，复用 Store 的修订机制。
4. 新建独立研究会话，在 380 V、220 V/50 Hz、20 kHz 闭环下验证额定、半载和额定至半载。每个工况保留基准与候选；额定先检查 400/800 步，失败则逐档加密至 3200。半载和阶跃根据 B 的已有证据从 1600/3200 步复核，保持原判据。
5. 对选择的电气运行重新求解 C，保存前后结果、参数、日志和摘要。仅计算已实际完成的对比，失败不隐藏。
6. 运行回归，更新交接与复现文档，发布精简证据供 A/B 审阅。

主要文件：`dcac_agent/candidate_revision.py`、`tests/test_candidate_revision.py`、`tools/run_lr_iteration.py`、`docs/LR_ALIGNMENT.md`。不修改 B 的控制器参数、收敛阈值或热源设定。
