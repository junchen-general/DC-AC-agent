## 损耗与结果边界

- 默认器件为 Infineon IPW65R041CFD7。参数依据制造商 Rev. 2.1 数据手册：RDS(on)=0.076 Ω（150 °C 测试点）、VSD=1.0 V、tr=12 ns、tf=3 ns、Qrr=1.2 μC；测试电流 24.8 A 明显高于本设计约 2.3 Arms。
- 闭环额定细步长账本：绕组常数 R 欧姆项 1.333 W、MOSFET 导通 0.810 W、开关重叠 0.468 W、死区二极管 0.164 W，部分模型合计 2.775 W。该合计排除磁芯、交流铜损、电容 ESR、栅极驱动、控制/辅助电源和热迭代，且绕组 0.25 Ω 无材料/温度依据，所以不用于整机效率声明。
- THD 之外另报告 10–30 kHz 与 30–50 kHz 开关频带 RMS，以及至 2.5fsw 排除 1–40 次谐波后的宽带残差；这些量不混称传统 THD。
- 早期 SPS 连续求解器结果出现非物理尖峰，已归档在 `validation_invalid_continuous_solver/` 并明确排除；正式 SPS 结果全部来自离散 `powergui`。

## 交付完整性与未完成依赖

每个正式 case 目录均包含可编辑 `.slx`、`waveforms.png`、`result.json`、`run_manifest.json` 和 `loss_basis_v1.json`。C 推荐的三项闭环细步长 case 保留完整 `electrical_raw_v1.mat`；粗步长与其他非推荐 case 的 MAT 可由各自 `request.json` 原样再生，当前为控制磁盘占用不全部保留。矩阵不保留重复 CSV 和旧 `simulation.mat`；独立 Agent 运行默认仍输出这些兼容文件。

B 的 2 mH/0.25 Ω 基准电气矩阵已完成并保留。C 随后交付的 E70 修订为 1.909 mH/0.2166 Ω，并在 `matlab/multiphysics/` 独立完成 500/750 W、400/800 步电气复验；该结果作为新的 C 设计修订保存，不覆盖 B 的 24 组基准矩阵。若后续要求四阶段全矩阵都采用 E70 参数，应继续建立新的联合修订并重跑，不能把 C 的独立复验等同于 B 全矩阵复验。
