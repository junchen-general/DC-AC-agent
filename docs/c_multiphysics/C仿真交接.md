# C 分工仿真交接

本研究包为滤波电感的电气—磁—热—力课程仿真。完整方案、参数来源和结果见 [C课程报告](C课程报告.md)；详细研究过程及其他候选见 [研究说明](研究说明.md)。

## 已交付

1. 设计对象：TDK N87 E70/33/32、2.5 mm 单片气隙、68 匝、64 股 × 0.15 mm 铜线截面积方案、B66372B1000T001 骨架；源参数见 `material_assumptions.json`。
2. 电气回填：目录 L=2.011 mH、二维 FE L=1.909 mH、R20=0.2166 Ω；500/750 W 的最终组合场统一使用二维 FE L，波形和指标在 `outputs/electrical_reference_400_E70FE68_500W/` 与 `outputs/electrical_reference_400_E70FE68_750W/`。
3. 磁场：二维线性 FE 网格、模型和云图在 `outputs/magnetic_e70/`；两档网格电感差 0.0067%。
4. 热—力：1 W 绕组/磁芯源场在 `outputs/unit_response_e70/`，组合 500/750 W 温度、位移、拉主应力场在 `outputs/e70_combined_scenarios/`；组合场具两档网格核查。
5. 候选改进：E55 → E70；同一电气模型下重新计算电流，比较磁芯直流偏置参考点、热响应和尺寸质量。

## 模型输入与结果口径

组合场环境为 40°C、外周对流 `h=10 W/(m²·K)`、前后端面绝热，额外绕组热与磁芯热各取 0.5 W。热场按线性源场叠加，铜电阻随峰值温度作单节点反馈；应力在二维平面应力模型中计算。500/750 W 最高温度分别为 71.42/97.49°C，最大位移 23.92/43.32 µm，磁芯选定探针拉主应力 4.74/8.68 MPa。角点应力峰值依赖网格，故不作为强度指标。

这些结果是所列计算输入下的仿真输出。磁场采用线性磁导率，热源中的 0.5 W+0.5 W 为指定计算工况；不要将二者写成材料损耗模型的预测值。`outputs/study_summary.json` 将未计算的实际磁芯损耗、交流铜损、饱和与强度裕度保留为 `null`。

## 与 A/B 对接

波形复核见 [波形与谐波复核](波形与谐波复核.md)。电气 PNG 已改用开关周期平均值、最小/最大值范围和局部全速波形，避免抽点产生的假包络。`result.json` 和 `handoff_local.json` 中的 `waveforms` 沿用稀疏瞬时预览，不应据此计算频谱或画纹波包络；分析请读 `simulation.mat` 或 `signals.csv`。电压、电感电流的 THD 分开列在 `outputs/waveform_audit/metrics.json`，统计区间为最后四个完整工频周期。E70 800 步运行用于检查 400 步结果，热—力组合场仍引用原来的 400 步运行。

B 提供设计修订、运行编号、完整电感电流/电压波形、采样间隔、L、R、功率工况与模型口径。C 返回候选版本、输入运行引用、磁/热/力模型版本、指标、网格检查、可编辑模型和图表路径。A 将结果按修订与运行编号关联显示，并区分线性场、组合热源仿真和未计算项目。小型元数据见 `outputs/study_summary.json`；完整工件的 SHA-256 清单见 `outputs/c_study_manifest.json`。

本地使用 MATLAB R2023b Update 7 与 PDE Toolbox；先运行 `run_e70_unit_response`、`run_e70_core_mesh_check`，再运行 `run_e70_combined_scenarios`。其他入口见报告和研究说明。主仓库的 A/B 接口尚需由负责人确认后集成。
