## 模型边界

默认阶段是**单相全桥理想开关函数＋LC状态方程，开环、单极性SPWM、40 ms软启动**。可在“编辑参数 → 模型阶段”选择器件级开环、含损耗开环或PR电压闭环，也可通过对话切换。

模型包含可打开的`SPWM`、`Full_Bridge`、`LC_Filter`子系统。全桥用`Vab = Vin * (Sa - Sb)`表示，桥臂下管采用互补信号；LC通过连续积分器计算：

```text
L * dIL/dt = Vab - rL*IL - Vout
C * dVout/dt = IL - Gload(t)*Vout
```

这是有实际开关脉冲和滤波动态的等效模型，**尚不是由四个Simscape半导体器件构成的器件级模型**。基础阶段不包含死区、开关/导通损耗或闭环；器件阶段提供死区，含损耗和闭环阶段提供初步损耗估计。三相或并网尚不支持。磁芯选型和磁/热/结构有限元位于独立的 `matlab/multiphysics/` 模块，E70 候选已可由网页调用。

不输出虚构的效率、结温、磁通密度或应力。给定绕组电阻损耗不等于整机总损耗。THD在末尾4个完整基波周期计算2–40次谐波，不含载波频段；它不是全频带失真指标，也不是实验测量值。

输出功率是基于**目标输出电压**选择电阻负载的额定值；实测仿真输出功率取决于实际输出电压。默认负载突变为0.12 s额定负载降到半载，变更前后仍为电阻负载。

基础阶段采用`ode4`固定步长`1/(100*fsw)`；器件阶段采用离散固定步长`1/(400*fsw)`、1 μs死区，闭环默认开启死区补偿。器件阶段需SPS工具箱且fsw至少10 kHz；闭环会校验补偿后的调制度上限。C 的独立复现副本已比较每开关周期 100—1600 步，并对 E70 的 500/750 W 工况进行了 400/800 步复核，见 [波形与谐波复核](docs/c_multiphysics/波形与谐波复核.md)。电压 THD 不代表电感电流的高频纹波；低次 THD 和磁链积分残差仍有步长敏感性。

## C 分工：滤波电感多物理场

集成版支持从当前 C 结果读取准确的 L 和 20°C 绕组电阻，另建修订并重算。规则模式依次使用“运行磁热力分析”“回填候选参数”“运行仿真”“运行磁热力分析”；Nanobot 对应工具为 `apply_candidate_parameters`。原 2 mH / 0.25 Ω 结果保留，候选结果另存。三个闭环负载工况的复验和步长检查见 [L/R 回填复验](docs/LR_ALIGNMENT.md)。下列 500/750 W 数值属于早期独立研究，不与集成版闭环结果混用。

最终课程算例采用 TDK N87 E70/33/32、2.5 mm 单片气隙和 68 匝绕组。二维线性磁场得到电感 1.909 mH，与绕组电阻 0.2166 Ω 一同回填电气模型；同时保留 E55 候选及厂商目录参数对照。

热—力算例取环境 40°C、外周对流系数 10 W/(m²·K)，额外绕组热和磁芯热各为 0.5 W，并迭代考虑铜电阻随温度变化。500/750 W 对应最高温度为 71.42/97.49°C。这些温度对应所列热源和边界条件，不能把两项 0.5 W 写成材料损耗模型的预测值。完整参数、位移、应力和网格检查见报告。

## MATLAB接入与故障恢复

默认自动检测`matlab.exe`，也可在设置中填写完整路径。当前机器安装路径为：

```text
D:/Program Files/MATLAB/R2025a/bin/matlab.exe
```

由于本机默认Python为3.14，首版默认采用`matlab -batch`，避免MATLAB Engine与Python版本兼容问题。每次任务独立启动进程，速度会慢于常驻Engine。

如果后台启动出现**5201**，表示MATLAB不能与所需MathWorks服务通信；这不代表电路模型已运行或已失败。先确认从桌面正常打开MATLAB是否可用。应用会保留任务日志。官方排查资料：

- https://www.mathworks.com/matlabcentral/answers/1815395-why-do-i-receive-error-5201-unable-to-access-services-required-to-run-matlab

可以点击“导出脚本，在已打开的MATLAB中执行”，复制对话给出的`run('.../run_in_matlab.m')`命令，在正常打开的MATLAB里执行。也可以在`outputs/<会话>/<运行>/`中打开`run_in_matlab.m`。**保留整个导出目录，包括 request.json、dcac_execute.m 及所有电气辅助脚本。**

脚本执行成功后，原运行目录会生成`.slx`和结果文件，刷新网页可以读取；如果把导出目录移动到别处，结果保存在新目录，需要手动查看，不会自动关联原网页会话。

若MATLAB首选项目录不可写，可将环境变量`DCAC_MATLAB_PREFDIR`指向专用可写目录。不要把“已检测到MATLAB路径”误认为“许可证或仿真已经验证”。

## 成员A：Nanobot模式与协作接口

规则模式仍只需Python标准库。Nanobot模式使用已验证的Python 3.14.6和nanobot-ai 0.3.5；其他Python版本尚未验证。

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install "nanobot-ai==0.3.5"
./.venv/Scripts/python.exe run_web.py
```

启动脚本和BAT会优先使用本项目.venv。网页设置中勾选“启用大模型工具调用”，选择“Nanobot 0.3.5”，填写支持Chat Completions工具调用的服务地址、模型和自己的API Key。关闭大模型恢复规则模式；原有自写循环保留在“兼容接口”选项。不要将密钥发到聊天或提交Git。

Nanobot只注册项目10个工具，不开放默认shell、文件操作或子代理工具。每个任务独立运行时，共享Store提供本会话最近16条消息；后台队列仍串行，最多12轮、3次MATLAB任务，支持取消。内部使用Nanobot的AgentLoop/ToolRegistry，已锁定版本，升级依赖需重新测试。密钥仅注入内存中的Nanobot配置；网页设置仍保存在被忽略的config.json。

每次电气任务生成run_manifest.json；C的multiphysics_result.json按协议交付后，网页刷新显示各域指标与PNG，检测归属并标记旧修订。新增 run_multiphysics 自动读取全采样电气数据并执行 E70 候选求解；结果格式合格不等于物理模型已充分验证。

## 自动磁热力求解

在结果页点击“运行磁热力分析”，或输入“对当前设计运行磁热力分析”。无当前修订电气结果时，对话工具自动先仿真；显式选择旧修订时会拒绝求解并提示重新仿真。旧电气导出缺少完整原始数据/身份字段时，也需要重新运行电气仿真。

当前固定为 E70 N87、68匝、2.5 mm气隙候选；读取电气运行末尾四个周期的全采样电感电流。默认环境40°C、对流10 W/(m²·K)、指定额外绕组热0.5 W和磁芯热0.5 W。大模型工具可传入这四项有范围限制的边界参数；规则模式和按钮使用默认值。

网页展示磁场、温度、应力、位移云图，输入条件及候选L/R相对电气参数的差异。**这是单向耦合候选分析，不会自动回填电路参数，不预测饱和、真实磁芯损耗或强度裕度。** 力场当前指热应力，不包含电磁力或磁致伸缩。详见 [C接入与验收](docs/C_AGENT_INTEGRATION.md)。
